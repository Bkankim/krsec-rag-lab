# 데이터 소스 라이선스 맵

이 리포가 다루는 원본 데이터의 소스별 라이선스, 확인일, 재배포 범위.
각 소스의 정책 원문 확인 결과를 여기에 기록하고, 리포에 포함되는 데이터 실물과 연결한다.

| 소스 | 라이선스 | 확인일 | 리포 포함 범위 |
|---|---|---|---|
| KISA 보안공지 (boho.or.kr) | 명시 라이선스 없음 (All rights reserved, 공공누리 마크 부재) | 2026-09-19 | 본문 재배포 불가. 수집 스크립트 + 메타데이터 인덱스(URL·제목·날짜·CVE ID)만 |
| NVD (nvd.nist.gov) | 미국 연방정부 저작물 (퍼블릭 도메인) + CVE 레코드는 MITRE 고지 재현 | 2026-09-19 | 평가용 서브셋 JSON 포함 가능. API 키는 커밋 금지 |
| CISA KEV | CC0 1.0 | 2026-09-19 | 스냅샷 포함 가능 |
| SigmaHQ rules | Detection Rule License 1.1 (author·원본 링크·고지 보존) | 2026-09-19 | 도입 시 DRL 전문 + 고지와 함께 (초기 범위 제외) |
| MITRE ATT&CK | 저작권 고지 문구 재현 의무 | 2026-09-19 | 도입 시 고지와 함께 (초기 범위 제외) |

주의: 위 확인은 1차 조사 기준이다. 각 소스를 실제로 리포에 넣기 전에 정책 원문을 재확인하고
이 표에 정책 URL을 추가한다. 노트북 출력·평가 로그·문서 인용에 KISA 본문이 새어 들어가는
경로도 커밋 전에 점검한다.
